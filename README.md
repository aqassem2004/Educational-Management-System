# Educational Management System

## Project Description
The **Educational Management System** is a comprehensive console-based application designed to manage educational institutions effectively. The system allows administrators, students, and educators to interact with various functionalities, such as user management, course management, and assignment handling. The primary goal is to streamline operations and provide an intuitive interface for all stakeholders.

## Features
- **User Authentication:** Secure sign-up and sign-in functionality.
- **Role-Based Access Control:** Separate roles for administrators, educators, and students.
- **Course Management:** Add, update, and delete courses.
- **Assignment Management:** Create, submit, and review assignments.
- **Data Persistence:** Efficient use of static dictionaries to manage entities like Users, Courses, and Assignments.

## Technologies Used
- **Programming Language:** C#
- **Platform:** Console Application
- **Programming Principles:**
  - Object-Oriented Programming (OOP)
  - Encapsulation through static dictionaries
  - Inheritance for code reuse and extensibility

## Key Principles Implemented
- **Encapsulation:** Static dictionaries store user, course, and assignment data securely.
- **Inheritance:** Shared behaviors and properties implemented across related classes to reduce redundancy.
- **Modularity:** Clear separation of concerns across different classes and methods.
- **Scalability:** The design allows for easy extension of functionalities.
